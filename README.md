# quieting-map

The human lane of the calm-room practice: a process map for humans to quiet the little dog nagging them, so they can settle down.

Built from the dwell-room work (October 2026), standing on four model receipts — Q, Bing, Astra, and Terra each found the same shape independently. The data lives in [still-water](https://github.com/MarkDude-design/still-water); the whole arc lives in [calm-room](https://github.com/MarkDude-design/calm-room).

- [quieting-map-v0.1.md](quieting-map-v0.1.md) — the map: the core (no furniture required), the furniture (optional helps), the limitations (disclosed, no shame).

The core asks nothing. The furniture is optional. The limitations are features.

Buddha may not have needed the incense. Could see it helping some folks.
